# Tankard

> *Skål.*

A Valheim mod by **Raven Iron**: booze that gets you drunk. Drinks add to a stacking intoxication meter. Time sobers
you up. The higher it climbs, the worse the symptoms: first a warm buzz, then a swaying camera and a stagger, and
finally a blackout. Make the cheap stuff at a station, or age the strong stuff in the fermenter.

**Not released.** This is a scaffold: the plugin loads and the intoxication maths is tested, but no drink exists in the
game yet.
